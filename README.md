# MCRD_PARIS_ISLAND
IMMERSIVE MILITARY ROBLOX GAME

All game code (Luau) lives in `src/` and syncs into Roblox Studio via Rojo.
See [SETUP.md](SETUP.md) for the one-time setup and daily workflow.

- `src/server/` — server scripts (game logic, scoring, NPCs)
- `src/shared/` — modules shared by server and client
- `src/client/` — client scripts (UI, local effects)
