# place/

Snapshots of the game exported from Roblox Studio, so Claude can read the map and
scripts.

**Studio → File → Save to File As…** → save here as **`.rbxlx`** (with the x — that's
the readable text format; `.rbxl` is binary and is ignored by git).

GitHub rejects files over 100 MB. If a snapshot is bigger than that, ask for a
scripts-only export instead.
